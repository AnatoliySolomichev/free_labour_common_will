# Архив переписки с Claude Code

Все чаты этого проекта, сложенные в каталог проекта — на смонтированный с хоста
том (`/workspace` = ext4 с хоста), поэтому **пересборка контейнера их не уносит**.

## Что внутри

| Каталог | Что | Формат |
|---|---|---|
| `raw/` | 23 сессии, родные транскрипты Claude Code | JSONL — **источник истины**, ничего не потеряно |
| `raw/memory/` | долговременная память Claude по проекту | Markdown |
| `raw/_global/` | `settings.json`, `history.jsonl` | без `.credentials.json` — секреты не копируются |
| `md/` | те же чаты для чтения и `grep` | Markdown |
| `html/` | те же чаты для чтения в браузере | HTML, самодостаточный |
| `INDEX.md` | оглавление | Markdown |

Имена файлов в `md/` и `html/`: `ГГГГ-ММ-ДД_ЧЧММ_<8 знаков id сессии>` — стабильны
между прогонами, сортируются по времени.

## Как читать

- **Браузер:** откройте `claude-history/html/index.html` — оглавление с фильтром,
  оттуда переход в любой чат. Реплики человека и Claude — карточками, размышления
  и вызовы инструментов свёрнуты в `<details>`, разворачиваются кликом.
  Тёмная/светлая тема — по настройке системы.
- **Из VS Code:** правый клик по `index.html` → *Open with Live Preview*;
  или на хосте открыть файл напрямую (том смонтирован).
- **Через сервер** (если браузер не видит файловую систему контейнера):
  `python3 -m http.server 8080 --directory claude-history/html`
- **Markdown:** `md/*.md` — читается в VS Code и на GitHub, удобно для поиска:
  `grep -rn "трудо-час" claude-history/md/`

## Обновить архив

```bash
./claude-history/backup.sh
```

Идемпотентно: слияние идёт по `uuid` записей, повторный запуск ничего не дублирует
и не укорачивает. Дописывает новое из `~/.claude/projects/-workspace/` и из старого
снимка `.claude-container-backup/`, затем перерисовывает `md/` и `html/`.

Запускать имеет смысл в конце рабочей сессии (или см. «Автоматически» ниже).

## Восстановить после пересборки контейнера

```bash
./claude-history/restore.sh     # затем перезапустить Claude Code
claude --resume                 # чаты снова в списке
```

Тоже слияние, а не перезапись: живые сессии в новом контейнере не затираются.

## Автоматически, по завершении каждой сессии

В `.claude/settings.json` (личный файл, он в `.gitignore`):

```json
{
  "hooks": {
    "Stop": [
      { "hooks": [ { "type": "command",
                     "command": "/workspace/claude-history/backup.sh >/dev/null 2>&1" } ] }
    ]
  }
}
```

## Формат raw

Одна строка JSONL = одна запись. Значимые типы:
`user` / `assistant` (реплики; `message.content` — блоки `text`, `thinking`,
`tool_use`, `tool_result`), `ai-title` (название чата), `file-history-*`
(снимки правок файлов), `mode`, `queue-operation` (служебные).
Рендер — `render.py`, слияние — `archive.py`; оба без зависимостей, только stdlib.
