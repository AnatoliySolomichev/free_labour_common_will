# Контекст проекта

## О проекте
Многомодульная распределённая система. Модули:
- Многопользовательский блокчейн (текущий фокус)
- Синхронизация блокчейнов
- Отображение текста в 3D и связи между текстами
- Экономика в блокчейне
- Универсальная распределённая база знаний

## Текущий фокус
Модуль блокчейна. Спецификация: `docs/blockchain.md`.
Этот документ — источник истины. При расхождениях между кодом и
документом — корректируется код, либо обновляется документ через явное обсуждение.

## Технологический стек
- Язык: C++17
- Сборка: CMake
- Среда разработки: Docker (Ubuntu LTS)
- Криптография: libsodium
- Хранилище: LMDB
- Сериализация: CBOR с deterministic encoding (RFC 8949 §4.2.1)
- Тесты: GoogleTest

## Конвенции кода
- Стандарт C++17, без зависимости от C++20+ возможностей.
- Стиль: snake_case для функций и переменных, PascalCase для классов и типов.
- Явное `noexcept` где применимо.
- Никаких голых `new`/`delete` — только умные указатели и RAII.
- Все криптоопераци через обёртки в `crypto::` namespace, не напрямую libsodium.
- Тесты обязательны для каждой публичной функции модуля.

## Ссылки на разделы документов
Нумерация разделов — **локальная для каждого документа**: `§3` есть и в
`blockchain.md`, и в `records.md`, и в `economy.md`, и это разные разделы.
Поэтому голая `§N` запрещена — по ней нельзя понять адресата.

- **Канон: `файл.md §N`, имя вплотную к номеру** — `records.md §11.2`,
  `blockchain.md §6.7 rule 9`. Это верно и внутри самого документа
  (в `economy.md` пишем `economy.md §4.3`, не `§4.3`), и в комментариях кода,
  и в строках, которые видит пользователь CLI. Смысл — любая строка,
  вырванная из контекста (выдача `grep`, кусок диффа, цитата в переписке),
  остаётся однозначной.
- Обратные кавычки вокруг ссылки целиком допустимы (`` `records.md §11.2` ``);
  кавычка **между** именем и номером — нет, она рвёт строку поиска.
- **Раздел, на который ссылаются, — заголовок, а не пункт списка.** Номера
  пунктов ползут при вставке; если на пункт нужна ссылка, поднимите его до `###`.
- **Номер раздела не переиспользуется.** Раздел удалён — номер уходит на пенсию
  (отсюда `economy.md §1а/§2а/§2б/§5а/§5б`: нумерация не сдвигалась, старые
  ссылки не сломались).
- Ссылки на внешние стандарты (`RFC 8949 §4.2.1`) под конвенцию не подпадают.
- `ИР-NNN` в `docs/dev-ideas.md` — отдельная сквозная система меток, не §.

Как найти:
```bash
python3 docs/check-refs.py                     # линтер: голые и битые ссылки
grep -rn "records.md §11.2" docs/ modules/     # кто ссылается
grep -nE "^#+ 11\.2\." docs/records.md         # где определён (заголовки — с #)
```

## Стиль работы
- Перед написанием нового кода — обсудить интерфейс.
- Перед существенными решениями (структуры данных, протоколы) — обновить
  соответствующий документ в `docs/`.
- Открытые вопросы из документов — не "решать молча", а явно обсуждать.
- Документы обновляются вместе с кодом, не отдельно.
